### 📝 Description
Build a simple mobile application using **Flutter** that displays basic personal information using various Flutter widgets. The app should present the information in a **visually clean card layout**.

---

### 🎯 Requirements

Your app must include the following elements:

- 🖼 **Profile Picture** (loaded from local assets)
- 👤 **Name**
- 📅 **Date of Birth / State**
- 📞 **Contact Icons** (e.g., email, phone, social media)
- 💬 **Short Quote or Bio**

---

### 🎨 Design Guidelines

- Use a **Card widget** for the main layout
- Ensure the UI is **clean, readable, and well-spaced**
- Apply consistent styling (fonts, colors, alignment)
- Make use of appropriate Flutter widgets (e.g., `Column`, `Row`, `CircleAvatar`, `Icon`)

---

### 📦 Expected Output

Students are required to submit:

1. 📸 **Screenshot of the App**
2. 🔗 **GitHub Repository Link** of the project

---

### 🚀 Example Widgets to Use

- `Scaffold`
- `AppBar`
- `Card`
- `CircleAvatar`
- `Text`
- `Icon`
- `Row` and `Column`

---

### 📌 Notes

- Ensure assets (images) are properly declared in `pubspec.yaml`
- Keep your code clean and well-organized
- Follow best practices in Flutter development
